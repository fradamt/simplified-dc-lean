## Review Focus

1. **The contest changes both viability and `lo`.** In a contest the root is `F` and `lo = H`, so the band is `{H}`: a block whose only witnesses have height `H−1` leaves `D`. In the uncontested or gap frame of the same blocks, `lo = H−1`. r148 §2 and the spec say that the code must change both viability and below-band eligibility (r148 N12). Eligibility and the walk are AP machinery and are not in this module. The AP obligation is `ap.headReachesLo.v1` (see "Out of scope"). The FG half is `lo` and `D`. Test: Task 6, Step 1, a contested view and the uncontested view of the same blocks, checked on `fjFrame` alone; and Task 7's `fjFrame_lo`, `fjFrame_D_viable`, `fjFrame_D_reachesLo` and `fjFrame_D_nonempty`.
2. **The cache frame is not a spec object.** The spec computes `fg_frame(Σ, V)` from the view. `Σ.h_max` is archival: only finality acceptance reads it, and no duty frame reads it (spec lines 358–360). r148 §2 says: "Do not calculate the contest from a live cache while calculating its height from a frozen view." The spec reads the cached J in one place only: `update_finality` tests `σ.F ⪯ Σ.J`. Task 7 proves the cache invariant for that test, and keeps `cacheFrame` only as a named comparison object. Test: Task 7 has a stale-cache example where `cacheFrame` and `fjFrame` differ.
3. **Natural-number subtraction in `H−1`.** `Height = ℕ` truncates `H−1` at `H ≤ 1`. Test: Task 6 has `decide` examples on the view `{genesis}` (`H = 1`, `Z = genesis`, `lo = 0`, `D = {genesis}`).
4. **The lex order on `(h_j, J.root)`.** Ties at one height are broken by root. Test: Task 6 has two blocks `B1a`, `B1b` (roots `⟨1⟩`, `⟨2⟩`), each justifying genesis at height 1 (one pair), and children `childA`, `childB` that justify `B1a` and `B1b` at height 2. These are two different justified entries at height 2. The frame's `J` is the height-2 entry with the greater root.
5. **Acceptance viability is not frame viability.** DC-fj's `viable_tree_from` (used only to accept a new F) keeps DC's `h_max − 1`. The frame uses `lo`. In a contest they differ. Test: Task 7 proves `frameViable ⊆ acceptanceViable` and equality without a contest, and gives a `decide` example of strict inclusion in a contest.

```lean
open AvailableChain

abbrev Height := Nat

/-- The height pair of a row, bound to an entry (port: DC/DecoupledConsensusModel/Objects/NamedBlocks.lean:31–48). -/
inductive NamedHeightPair where
  | empty
  | vote (height : Height) (entry : BlockId) (timeout : Bool)
  deriving DecidableEq, Repr

namespace NamedHeightPair
/-- Targets and timeouts use the same height and entry match. -/
def matchesEntry (height : Height) (entry : BlockId) : NamedHeightPair → Bool
  | .empty => false
  | .vote h target _ => decide (h = height ∧ target = entry)
end NamedHeightPair

/-- The finality pair `(h_f, T_f)` (port: DC/DecoupledConsensusModel/Objects/Blocks.lean:60–66). -/
structure FinalityPair where
  height : Height
  target : BlockId
  deriving DecidableEq, Repr

/-- One FG row: signer, height pair, finality pair. No SG field. -/
structure Row (V : Type) where
  signer : V
  height_pair : NamedHeightPair
  finality_pair : Option FinalityPair
  deriving DecidableEq, Repr

/-- A block as the FG reads it. The AP maps its blocks to this type later. -/
inductive FGBlock (V : Type) where
  | genesis
  | node (parent : FGBlock V) (slot : Slot) (root : BlockId) (rows : List (Row V))
  deriving DecidableEq, Repr

namespace FGBlock
variable {V : Type}
def slot : FGBlock V → Slot
  | .genesis => 0
  | .node _ s _ _ => s
def root : FGBlock V → BlockId
  | .genesis => genesisRoot
  | .node _ _ r _ => r
def parent : FGBlock V → FGBlock V
  | .genesis => .genesis
  | .node p _ _ _ => p
def rows : FGBlock V → List (Row V)
  | .genesis => []
  | .node _ _ _ rs => rs

variable [DecidableEq V]
def preceq (A : FGBlock V) : FGBlock V → Bool
  | .genesis => decide (A = .genesis)
  | B@(.node p _ _ _) => decide (A = B) || preceq A p
def Preceq (A B : FGBlock V) : Prop := preceq A B = true
instance (A B : FGBlock V) : Decidable (Preceq A B) :=
  inferInstanceAs (Decidable (preceq A B = true))
def compatible (A B : FGBlock V) : Bool := preceq A B || preceq B A
end FGBlock

/-- The rows carried by the chain that ends at `B` (port: DC/DecoupledConsensusModel/Protocol/Evidence.lean `chain_attestations`). -/
def chainRows {V : Type} [DecidableEq V] : FGBlock V → Finset (Row V)
  | .genesis => ∅
  | .node p _ _ rs => rs.toFinset ∪ chainRows p

/-- Fixed positive weights (port: DC/DecoupledConsensusModel/Objects/Weights.lean:49–78). FG-SA uses weight 1. -/
structure Electorate (V : Type) [Fintype V] where
  weight : V → Nat
  weight_pos : ∀ i, 0 < weight i

namespace Electorate
variable {V : Type} [Fintype V] [DecidableEq V]
def totalWeight (E : Electorate V) : Nat := ∑ i, E.weight i
def weightOf (E : Electorate V) (S : Finset V) : Nat := ∑ i ∈ S, E.weight i
/-- `q = ⌈2W/3⌉`; with unit weights this is FG-SA's `q_F = (2n+2) div 3`. -/
def q (E : Electorate V) : Nat := (2 * E.totalWeight + 2) / 3
def IsQuorum (E : Electorate V) (S : Finset V) : Prop := E.q ≤ E.weightOf S
end Electorate
```
